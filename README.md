# orchestra + tapntax

Two projects from the Cursor Hackathon at Taxfix, Berlin, September 2026.

- `orchestra/`: agent orchestration with a permission gate, a cost cascade and a measured comparison. Python 3 standard library only. Start with `orchestra/README.md`.
- `tapntax/`: a card payment arrives, the phone asks one question, one tap files the expense. Start with `tapntax/README.md`.

No keys are included. Each project has a `.env.example`: copy it to `.env` and fill in your own values.
